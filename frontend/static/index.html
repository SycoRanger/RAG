About this project

An intermediate Retrieval-Augmented Generation system built for an Applied LLM Systems assignment. PDFs are parsed, chunked, embedded via Pinecone's hosted Inference API, indexed in a Pinecone serverless vector database, and retrieved with cosine-similarity thresholding before an LLM (Groq) generates an answer restricted strictly to the retrieved context. Every answer carries its exact source: document name, page number, chunk ID, and similarity score.
