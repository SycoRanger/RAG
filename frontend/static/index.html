Enabling OCR

OCR needs the Tesseract program, which pip can't install because it isn't a Python package.
  1. Windows: install the UB Mannheim build. macOS: brew install tesseract. Ubuntu/Debian: sudo apt install tesseract-ocr.
  2. On Windows, add this to .env and restart the backend:
TESSERACT_CMD=C:\Program Files\Tesseract-OCR\tesseract.exe
